# REST API Reference

This reference follows the Spring MVC mappings in `BE/src/main/java/com/example/winter_olympics/controller/` and the matchers in `SecurityConfig`. Base path: `/api`. Request and response JSON uses camelCase. Unless noted otherwise, entity-backed numeric IDs are generated by JPA.

## Access Labels

- **Public**: no login required.
- **Authenticated**: either `ATHLETE` or `ADMIN` with a valid Bearer token, unless a controller adds an ownership restriction.
- **ADMIN**: `ROLE_ADMIN` required.
- **ATHLETE / ADMIN**: either listed role.

Successful collection reads return JSON arrays. `POST` create operations marked `201` return a JSON representation. `204` operations return no content. Some CRUD controllers return JPA entities directly; their JSON shape follows the entity getters and should not be treated as a versioned DTO contract.

## Authentication

| Method | Path | Access | Request | Response / behavior |
| --- | --- | --- | --- | --- |
| `POST` | `/api/auth/register` | Public | `{ "username": "...", "password": "..." }` | `201`; `{ token, username, role }`, with role `ATHLETE`. Non-null `athleteId` is rejected with 400. Duplicate username is 400. |
| `POST` | `/api/auth/login` | Public | `{ "username": "...", "password": "..." }` | `200`; `{ token, username, role }`. Invalid credentials return 401. |

## Athletes

Athlete body: `{ "name": "...", "countryId": 1, "gender": "MALE", "dateOfBirth": "YYYY-MM-DD" }`. Gender is `MALE` or `FEMALE`. Name, country ID, gender, and birth date are required.

| Method | Path | Access | Response / behavior |
| --- | --- | --- | --- |
| `GET` | `/api/athletes` | ADMIN | All athletes as `AthleteResponse[]` (`id`, `name`, `countryId`, `country`, `gender`, `dateOfBirth`). |
| `GET` | `/api/athletes/me` | ATHLETE / ADMIN | Linked athlete for the authenticated username as `AthleteResponse`; 404 if user/profile is missing. Does not accept an ID. |
| `GET` | `/api/athletes/{id}` | ADMIN | One `AthleteResponse`; 404 if absent. |
| `POST` | `/api/athletes` | ADMIN | `201`; created Athlete entity. Missing country returns 404. |
| `PUT` | `/api/athletes/{id}` | ATHLETE / ADMIN + ownership | Updated Athlete entity. ATHLETE may modify only their linked athlete; ADMIN bypasses ownership check. |
| `DELETE` | `/api/athletes/{id}` | ATHLETE / ADMIN + ownership | `204`; only own athlete for ATHLETE, any athlete for ADMIN. FK conflicts return 409. |

## Countries

Country request body is an entity-shaped JSON object with a `name` field. There is no dedicated country request DTO or Bean Validation on these controller methods.

| Method | Path | Access | Response / behavior |
| --- | --- | --- | --- |
| `GET` | `/api/countries` | Authenticated | All countries. |
| `GET` | `/api/countries/{id}` | Authenticated | One country; 404 if absent. |
| `POST` | `/api/countries` | ADMIN | Saves a country; returns the saved entity. |
| `PUT` | `/api/countries/{id}` | ADMIN | Changes the country name; 404 if absent. |
| `DELETE` | `/api/countries/{id}` | ADMIN | Deletes the country; 404 if absent, 409 on a database constraint conflict. |

## Competitions

Request body: `{ "name": "...", "type": "SKI_SLALOM", "gender": "MALE", "minimumAge": 18, "numberOfLaps": null, "shootingAfterLaps": null }`. Type is `SKI_SLALOM` or `BIATHLON`; gender is `MALE` or `FEMALE`.

| Method | Path | Access | Response / behavior |
| --- | --- | --- | --- |
| `GET` | `/api/competitions` | Public | Competition entities. |
| `GET` | `/api/competitions/{id}` | Public | One competition; 404 if absent. |
| `POST` | `/api/competitions` | ADMIN | `201`; created competition entity. |
| `PUT` | `/api/competitions/{id}` | ADMIN | Updated competition entity; 404 if absent. |
| `DELETE` | `/api/competitions/{id}` | ADMIN | `204`; 404 if absent and 409 on database constraint conflict. |

Name/type/gender are required; minimum age, laps, and shooting lap have `@Min(1)` validation (the nullable lap fields may be omitted for validation and then are checked against competition type). BIATHLON requires both lap settings, with `shootingAfterLaps <= numberOfLaps`; SKI_SLALOM requires both values to be null.

Athlete birth date is required but the DTO does not apply a past-date constraint. The registration age calculation still compares the submitted date against the current date and rejects athletes whose calculated age is below the competition minimum.

## Registrations

Create body: `{ "athleteId": 1, "competitionId": 1 }`. Both IDs are required. The response DTO contains `id`, `athleteId`, `athleteName`, `competitionId`, and `competitionName`. No registration status field is stored or returned.

| Method | Path | Access | Response / behavior |
| --- | --- | --- | --- |
| `GET` | `/api/registrations` | Authenticated | ADMIN receives all registrations; ATHLETE receives only registrations for the linked athlete (or an empty list when no profile is linked). |
| `POST` | `/api/registrations` | Authenticated + ownership | `201`; creates registration for self for ATHLETE, any athlete for ADMIN. Checks gender, current age vs minimum age, and duplicates. |
| `DELETE` | `/api/registrations/{id}` | Authenticated + ownership | `204`; ATHLETE may delete only own registration; ADMIN may delete any. |

Gender mismatch, age below minimum, and duplicate registration are 400 business errors. A foreign athlete registration or unregister attempt is 403.

## Slalom Results

Result body: `{ "registrationId": 1, "time": 52.341, "finished": true }`. Registration and time are required; time must be at least `0.001`, and `finished` is required.

| Method | Path | Access | Response / behavior |
| --- | --- | --- | --- |
| `POST` | `/api/slalom-results/first-run` | ADMIN | `201`; upserts the registration's first-run result and resets second-run fields. Registration must belong to a Slalom competition. |
| `POST` | `/api/slalom-results/second-run` | ADMIN | Saves second run; registration must be Slalom, have a finished first run, and qualify for the second run. Returns the Slalom result entity. |
| `GET` | `/api/slalom-results/second-run/participants/{competitionId}` | ADMIN | Qualified finished first-run participants, ordered by first-run time. |
| `GET` | `/api/slalom-results/second-run/start-order/{competitionId}` | ADMIN | Qualified participants in reverse first-run order. |
| `GET` | `/api/slalom-results/ranking/{competitionId}` | Public | Completed Slalom ranking DTOs: position, athlete, country, first/second run time, final time. |

The first-run and second-run write operations return JPA `SlalomResult` entities. Result rows are located by registration, and saving an existing registration updates its row.

## Biathlon Results

Request body: `{ "registrationId": 1, "skiTime": 1450.250, "misses": 2, "penaltyPerMiss": 60.000, "finished": true }`. Registration, ski time, penalty per miss, and finish flag are required; ski/penalty times must be at least `0.001`; misses must be nonnegative.

| Method | Path | Access | Response / behavior |
| --- | --- | --- | --- |
| `POST` | `/api/biathlon-results` | ADMIN | `201`; result DTO with ski time, misses, penalty-per-miss, derived penalty time, final time, and finish flag. Registration must belong to a configured BIATHLON competition. |
| `GET` | `/api/biathlon-results/ranking/{competitionId}` | Public | Completed ranking DTOs: position, athlete, country, ski time, misses, penalty time, final time. |

Penalty time is the miss count multiplied by the per-miss penalty. Final time is returned for finishers only.

## Rankings

Ranking routes are the public `GET /api/slalom-results/ranking/{competitionId}` and `GET /api/biathlon-results/ranking/{competitionId}` listed above. Rankings are calculated from stored result rows; there is no separate ranking table or CRUD endpoint.

## Medals

| Method | Path | Access | Response / behavior |
| --- | --- | --- | --- |
| `GET` | `/api/olympics/medals` | Public | Country medal counts: country, gold, silver, bronze, total. Sorted by gold, then silver, then bronze descending. |
| `GET` | `/api/olympics/medals/slalom/{competitionId}` | Public | Up to the top three ranked Slalom athletes as position/name/country/medal. |
| `GET` | `/api/olympics/medals/biathlon/{competitionId}` | Public | Up to the top three ranked Biathlon athletes as position/name/country/medal. |

Medals are derived on request: positions 1, 2, and 3 map to gold, silver, and bronze. There is no persisted medal table.

## Statistics

| Method | Path | Access | Response / behavior |
| --- | --- | --- | --- |
| `GET` | `/api/olympics/statistics` | Public | `averageParticipantAge`, `youngestMedalist`, and `oldestMedalist` (`athleteName`, `age`). Average age uses distinct athletes with registrations and is rounded to two decimals; no participants gives `0.0`. Medalist fields are null when no medalists are found. |

## Admin / Test Data

| Method | Path | Access | Response / behavior |
| --- | --- | --- | --- |
| `POST` | `/api/admin/test-data` | ADMIN | `200`; a message, created/reused counts, and demo athlete usernames. Requires backend `DEMO_ATHLETE_PASSWORD`; no request body is required. The password is not returned. |
| `POST` | `/api/admin/reset-data` | ADMIN | Deletes all application data and user accounts except the currently authenticated admin. Requires JSON `{ "confirmation": "DELETE ALL OLYMPICS DATA" }`; a response identifies the preserved admin. This does not drop the schema. |

The endpoint is intended for controlled demonstration/test data, not production business data. See [Testing](testing.md#demo-test-data).

## Validation and Error Handling

The global exception handler returns a JSON object with `timestamp`, `status`, `error`, and `message` for handled API errors.

| Status | Actual mapping |
| --- | --- |
| `400 Bad Request` | Bean Validation errors, malformed request bodies, enum/date parse errors, and explicit business-rule failures. |
| `401 Unauthorized` | Missing/invalid authentication for protected routes and invalid login credentials. |
| `403 Forbidden` | Authenticated principal lacks the required role or fails controller-level athlete ownership checks. |
| `404 Not Found` | Typed not-found exceptions for missing users, athletes, countries, competitions, registrations, or required results. |
| `409 Conflict` | `DataIntegrityViolationException`, returned with a generic conflict message for database constraint conflicts. |
| `500 Internal Server Error` | Unexpected runtime or other exceptions; response message is generic and does not include the exception detail. |

Security filter-chain errors return 401/403 through Spring Security. The global JSON handler is applied to controller/application exceptions; exact response formatting for framework-level errors can differ.
